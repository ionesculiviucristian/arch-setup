# Gaming

Installed with `./install.sh gaming`, which installs [base](../base/README.md) first.

## Official Arch packages

- [GameMode](https://github.com/FeralInteractive/gamemode/): A daemon/lib combo that allows games to request a set of optimisations be temporarily applied to the host OS
- [GameMode (32-bit)](https://github.com/FeralInteractive/gamemode/): A daemon/lib combo that allows games to request a set of optimisations be temporarily applied to the host OS
- [gamescope](https://github.com/ValveSoftware/gamescope/): SteamOS session compositing window manager
- [python-vdf](https://github.com/solsticegamestudios/vdf/): Library for working with Valve's VDF text format
- [Steam](https://steampowered.com/): Valve's digital software delivery system
